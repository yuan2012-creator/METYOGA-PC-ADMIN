## 2. memberQuery 定位

- **只读查询**：仅返回会员维度只读数据，用于列表与详情展示。  
- **不做**：会员新增、修改、删除。  
- **不写**：跟进记录、标签、资产、订单、操作日志（本接口范围内）。  
- **后续真实写入**：须另走 **`memberCommand`**（或等价命令接口）及**独立审批 / 审计流程**；不得借 `memberQuery` 夹带写操作。

## 4. 入参设计

### 4.1 建议请求体字段（JSON）

| 字段 | 类型建议 | 说明 |
|------|----------|------|
| `page` | number | 页码，从 1 开始。 |
| `pageSize` | number | 每页条数。 |
| `cursor` | string \| null | 可选；**第一版可不用**，预留大列表游标分页。 |
| `q` | string \| null | 搜索关键词：支持 **会员姓名**、**手机后四位**、**会员编号**（具体匹配规则由后端定义并文档化）。 |
| `memberId` | string \| null | 有值：**单个会员详情**；无值：**列表**（配合分页与筛选）。 |
| `storeId` | string \| null | 单店过滤（与权限求交）。 |
| `storeIds` | string[] \| null | 多店过滤（**必须与**当前用户可访问门店集合求交）。 |
| `lifecycleStatus` | string \| null | 生命周期状态筛选（枚举值由后端定义）。 |
| `stage` | string \| null | 阶段/漏斗阶段筛选。 |
| `riskTag` | string \| null | 风险标签筛选。 |
| `from` | string \| null | 时间范围起（ISO 8601 或约定格式）。 |
| `to` | string \| null | 时间范围止。 |
| `role` | string \| null | **仅作提示或审计回显**；**权限以后端登录态为准**，不得单独依赖前端传入 `role` 授权。 |
| `requestId` | string | 全链路追踪 ID，建议必填。 |

### 4.2 行为规则

- **`memberId` 有值**：返回**单个**会员详情（或 404）；仍须校验该会员是否在**当前用户门店权限**内。  
- **`memberId` 无值**：返回**列表**，受分页与筛选约束。  
- **`q`**：语义见上表；空字符串视为不搜索。  
- **`storeId` / `storeIds`**：后端必须根据**当前登录用户**解析出允许访问的门店集合，与入参求交；**禁止**仅信任前端传的门店 ID 扩大范围。  
- **`role`**：**不能完全相信前端**；鉴权与数据范围以**服务端会话 / Token 解析结果**为准；前端传入的 `role` 若与后端不一致应忽略或记审计日志。

## 5. 出参设计

### 5.1 统一包装（与 `ReadonlyApiResult` 对齐）

| 字段 | 说明 |
|------|------|
| `data` | 列表为数组；详情为**单个对象**；错误时为 `null`。 |
| `meta` | 分页与 `requestId`、`total`、`hasMore`、`page`、`pageSize` 等（与现有只读 meta 可映射）。 |
| `error` | 失败时非空：`code` + `message`。 |

### 5.2 `data` 列表项：每个会员至少包含

| 字段 | 说明 |
|------|------|
| `id` | 会员主键。 |
| `name` | 展示名。 |
| `phoneMasked` | **脱敏后**手机号展示（不返回完整手机号）。 |
| `gender` | 性别枚举或展示值。 |
| `avatar` | 头像 URL 或空。 |
| `lifecycleStatus` | 生命周期状态。 |
| `stage` | 阶段/漏斗。 |
| `leadStatus` | 潜客/线索状态（若无则占位或 null）。 |
| `riskTag` | 风险标签（可多值时可用数组，由契约固定）。 |
| `primaryStoreId` | 主归属门店。 |
| `managerId` | 责任顾问/管家 ID（可空）。 |
| `managerName` | 责任顾问展示名（可空）。 |
| `joinedAt` | 入会/建档时间。 |
| `lastVisitedAt` | 最近到店或最近活跃时间（语义由后端定义）。 |
| `totalLTV` | 累计贡献/消费口径（**数值口径须在契约附录写死**）。 |
| `points` | 积分或可展示积分口径。 |
| `totalClasses` | 累计上课节数或等价指标。 |
| `tags` | 标签列表（只读展示）。 |
| `updatedAt` | 最近更新时间。 |

### 5.3 详情在列表字段基础上可增加

| 字段 | 说明 |
|------|------|
| `bodyTags` | 体态/身体维度标签（若有）。 |
| `timelineSummary` | 时间线摘要（非完整时间线写入）。 |
| `latestFollowUp` | 最近跟进摘要（只读快照，非写跟进接口）。 |
| `assetSummary` | 资产摘要（非 `memberAssetQuery` 全量时可精简）。 |
| `bookingSummary` | 预约摘要。 |
| `consumptionSummary` | 课消/消费摘要。 |
| `orderSummary` | 订单摘要。 |

**说明**：详情扩展字段可与独立查询（如 `memberAssetQuery`）分工，避免 `memberQuery` 无限膨胀；具体以评审为准。

## 6. 权限与脱敏

| 角色 / 场景 | 数据范围 | 脱敏与其它 |
|-------------|----------|------------|
| 总部管理员 | 可查看**全部门店**（在 RBAC 定义内） | 手机号仍建议默认脱敏；按需开通完整查看须另案。 |
| 店长 | **本店或授权门店** | 手机号脱敏策略与总部一致或更严。 |
| 财务 | 经营所需字段 | **手机号等隐私必须脱敏**；仅返回财务核对必要字段（字段白名单可另表）。 |
| 老师 | **仅与自己相关**的会员（规则由后端定义：授课关系、预约关系等） | **手机号必须脱敏**。 |
| 投资人 | **仅汇总** | **不应**直接调用 `memberQuery` 拉会员明细；若存在该角色，应在网关层拒绝或返回 403。 |
| 合作门店管理员 | **本合作店**会员 | 与门店授权表一致；越权 403。 |
| 通用 | 默认 | **不返回完整手机号**；使用 `phoneMasked`。 |
| P0 范围 | 敏感字段 | **身份证、住址等**不进入 P0 `memberQuery` 响应。 |

## 7. 错误码

建议 `error.code` 使用稳定机器可读枚举（与 HTTP 状态可组合映射）：

| code | 典型含义 | HTTP 建议 |
|------|----------|-----------|
| `VALIDATION_ERROR` | 参数非法、分页越界、`from`/`to` 反了等 | **422** |
| `UNAUTHORIZED` | 未登录或 Token 无效 | **401** |
| `FORBIDDEN` | **无权限或越店**（有登录但不可访问该资源/门店） | **403** |
| `NOT_FOUND` | `memberId` **不存在**或无权视为不存在（由安全策略二选一并在文档固定） | **404** |
| `BUSINESS_RULE` | 业务规则不满足（非参数格式问题） | **422** |
| `INTERNAL_ERROR` | 未预期服务端错误 | **500** |

**语义约定**：

- **403**：无权限或越店；**不得**返回其它门店会员数据。  
- **404**：`memberId` 不存在（或策略上「无权即 404」时等同）。  
- **422**：业务规则不满足（与 `VALIDATION_ERROR` 可合并或细分，须在契约中固定一种）。  
- **网络失败**：由前端 **`apiClient` 统一处理**（超时、DNS、断网等），映射为前端可读错误态，**不**混入后端 `error.code`。

## 8. 分页与筛选

- **第一版**：**`page` + `pageSize`** 即可。  
- **`cursor`**：可作为后续大列表优化项，第一版可为空忽略。  
- **`pageSize` 最大值**：建议 **100**（后端强制截断并可在 `meta` 中提示）。  
- **默认排序**：按 **`updatedAt` 或 `joinedAt` 倒序**（**必须二选一并写死**在契约附录；若按 `q` 搜索可另定义相关性排序并说明）。  
- **`from` / `to`**：必须明确过滤的是 **`joinedAt`** 还是 **`updatedAt`**（或其它业务时间）；**禁止**语义模糊。  
- **多门店查询**：**必须**受权限限制；仅返回用户有权门店内的会员。

## 9. 与前端现有类型映射

- 后端 **snake_case** 字段由 **`memberAdapter`** 统一转为 **camelCase**；与现有 `Member` 等类型对齐。  
- 前端 **`Member` 类型**（`types.ts`）**保持不变**；新增后端字段时优先在 adapter 层映射到现有字段或扩展类型（由后续 live 接入 MR 处理，**不在本文档改代码**）。  
- **缺失字段**：由 **adapter 兜底**（安全默认值），避免 UI 崩溃。  
- **不允许**组件直接处理 **snake_case**。  
- **不允许**组件直接调用云函数或直连 HTTP。

## 11. 验收标准（live 接入完成后对照）

| # | 标准 |
|---|------|
| 1 | **mock 模式仍可用**（未开启 live 时行为不变）。 |
| 2 | **live 模式可通过配置开启**（环境或特性开关）。 |
| 3 | `memberQuery` **列表成功**时，`Members` 列表能加载。 |
| 4 | `memberQuery` **详情成功**时，详情能打开。 |
| 5 | **空数据**时展示**空态**（非错误）。 |
| 6 | **失败**时展示**错误态**（不白屏）。 |
| 7 | **越店**时**不能**返回他店会员数据（403 或安全等价策略）。 |
| 8 | **不返回完整手机号**（仅 `phoneMasked` 或等价）。 |
| 9 | **不返回**身份证、住址等敏感字段。 |
| 10 | **不写数据库**；**不改会员状态**。 |
| 11 | **不影响** Mall / Courses / Finance / Dashboard / Staff 等未接入模块的 mock 行为。 |
| 12 | **`npm run build` 通过**。 |
