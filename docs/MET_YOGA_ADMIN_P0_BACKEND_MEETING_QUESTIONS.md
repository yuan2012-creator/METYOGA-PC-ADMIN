# MET YOGA 管理后台 · P0 后端对接会议问题清单 v1

**读者**：程序员、后端、云函数负责人、前端对接人

**范围**：本轮**仅新增本文档**；**不修改**业务代码。

## 6. 每个 Query 的关键确认问题

### 6.1 memberQuery

- `members` 集合（或实际表名）**是否存在**？  
- 是否支持**会员列表与详情共用一个** Query（`memberId` 有值即详情）？  
- 手机号是否**默认脱敏**？算法与展示格式？  
- 是否返回 **`lifecycleStatus` / `stage` / `riskTag`**？  
- 是否支持 **`q` 搜索**（姓名 / 手机后四位 / 会员编号）？  
- 是否支持**门店过滤**？  
- 是否支持**分页**？  
- **投资人是否禁止**调用会员**明细**（网关策略）？

### 6.2 memberAssetQuery

- `member_assets`（或实际表名）**是否存在**？  
- **资产状态**是否由**后端统一返回**？  
- 是否支持 **`memberId`** 查询？  
- 是否支持 **`orderId`** 查询？  
- 是否支持 **`assetId` 详情**？  
- 是否返回**订单 / 合同 / 产品**关联字段？  
- 是否返回**临期资产筛选**字段（如 `expiringBefore`）？  
- 是否**禁止前端推断**资产状态（仅展示后端字段）？

### 6.3 orderQuery

- **`orders` / `order_items`**（或实际表名）**是否存在**？  
- **金额单位**是**分**还是**元**？  
- 是否返回 **`orderItems`**？  
- **`orderStatus`** 是否**后端统一返回**？  
- **`paymentStatus` / `contractStatus` / `assetStatus`** 是否作为**摘要**返回？  
- 是否支持**订单编号 / 会员 / 产品**搜索？  
- 是否支持**订单详情**？  
- 是否**禁止** Query 做任何**订单写入**？

### 6.4 contractQuery

- **`contracts`**（或实际表名）**是否存在**？  
- 合同文件是 **`fileId`** 还是 **`secureUrl`**？  
- 合同文件 URL **有效期多久**？  
- 是否返回 **`importantTerms`**？  
- 是否返回 **`templateId` / `templateName`**？  
- 是否返回 **`contractStatus`**？  
- 是否**禁止长期公开**文件链接？  
- 是否**不返回身份证 / 住址**？

### 6.5 paymentQuery

- **`payments`**（或实际表名）**是否存在**？  
- **`paymentStatus`** 是否**后端统一返回**？  
- **`reconciledStatus`** 是否已有？  
- **`transactionNo`** 是否**默认脱敏**？  
- **完整流水号**谁能看（角色白名单）？  
- **金额单位**是**分**还是**元**？  
- 是否支持 **`orderId`** 查询？  
- 是否**禁止** Query 生成**对账 / 入账**动作？

### 6.6 courseSessionQuery

- **`course_sessions`**（或实际表名）**是否存在**？  
- **`startAt` / `endAt` 时区策略**是什么？  
- **`publishStatus` / `bookingStatus` / `sessionStatus` / `exceptionStatus` / `settlementStatus`** 是否均由**后端返回**？  
- 是否返回 **`bookedCount` / `checkedInCount` / `attendedCount`**？  
- 是否支持按**当日时间窗**查询？  
- **老师**是否**只能查本人场次**？  
- 是否**禁止**前端根据时间**自行判定完课**？

### 6.7 bookingQuery

- **`bookings`**（或实际表名）**是否存在**？  
- **`bookingStatus`** 是否**后端统一返回**？  
- **`waitlistRank`** 是否已有？  
- **`late_cancelled` / `no_show` 规则**由谁定义？  
- 是否支持 **`courseSessionId`** 查询预约名单？  
- 是否支持 **`memberId`** 查询会员预约？  
- **老师**是否**只能查本人课程预约**？  
- 是否**禁止** Query **改预约状态**？

### 6.8 attendanceQuery

- **`attendances`**（或实际表名）**是否存在**？  
- **`attendanceStatus`** 是否**后端统一返回**？  
- **`checked_in` / `attended` / `consumed` 边界**由谁定义？  
- **补签**是否有 **request / approval** 表？  
- **`no_show` / `absent` 规则**由谁定义？  
- 是否支持 **`courseSessionId`** 查询签到名单？  
- 是否支持 **`memberId`** 查询到课记录？  
- 是否**禁止** Query **生成耗课**？

### 6.9 consumptionQuery

- **`consumptions`**（或实际表名）**是否存在**？  
- **`consumptionStatus`** 是否**后端统一返回**？  
- **`amount` 单位**是**分**还是**元**？  
- **`posted`** 语义是**耗课确认**还是**财务过账准备**？  
- 耗课是否由**签到自动生成**（规则归属）？  
- **冲正**是否单独有 **reverse** 表或字段集？  
- 是否支持 **`memberAssetId`** 查询？  
- 是否**禁止** Query **生成确认收入 / 分录 / 老师课时费**？
